# 既存機能チェックリスト（SD-001）

v0.0.4 の既存機能を、v0.1.0 の改修中に失っていないか確認するための実機チェックリスト。
各行は VS Code 上で目視・操作して確認する。自動テストで代替できない項目が対象。

実施状況の記録欄は SD-027（実機E2E）と SD-029（VSIX検証）で埋める。SD-001時点では未実施。

## 対象の解決と表示

- [ ] Explorer で `.sln` を右クリック → 「Show Dependency Map」でマップが開く
- [ ] Explorer で `.slnx` を右クリック → 同上
- [ ] Explorer で `.csproj` を右クリック → そのプロジェクトと推移参照が表示される
- [ ] コマンドパレットの「SharpDeps: Show Dependency Map」で直近の対象が使われる
- [ ] パネルタイトルが `SharpDeps — <ソリューション名>` になる
- [ ] タブを閉じて再度開くと復元される（`retainContextWhenHidden` の現行挙動）

## 粒度と表示

- [ ] Projects / Namespaces を切り替えると、選択状態が壊れず再描画される
- [ ] プロジェクト種別ごとの色と凡例が表示される（web / library / test / desktop / app）
- [ ] 凡例は現在のグラフに存在する種別のみを列挙する
- [ ] テストプロジェクトの表示/非表示トグルが動作し、非表示時は再レイアウトされて詰まる
- [ ] ノード間隔・ランク間隔スライダーでレイアウト密度が変わる
- [ ] グラフと循環サイドバーのスプリッターで幅を変更できる

## 操作

- [ ] ノードをクリックすると接続関係がハイライトされ、サイドバーに詳細が出る
- [ ] 循環に含まれるノードと辺が赤で強調される
- [ ] ズームボタン、ズームスライダー、Ctrl/Cmd+ホイール、ピンチ、ドラッグで移動できる
- [ ] Fit で全体が収まり、ウィンドウリサイズ後も再フィットする
- [ ] 再描画しても選択が不意に失われない

## 循環

- [ ] サイドバーの循環一覧から項目を選ぶと該当ノードへ移動する
- [ ] Problems パネルに循環の診断が出る（プロジェクトは `.csproj`、名前空間は代表ファイルに紐づく）
- [ ] 名前空間の代表ファイルが無い循環は診断が無理に紐づかず、警告として扱われる

## 出力

- [ ] 「Copy Mermaid Source」でMermaidソースがクリップボードへ入る
- [ ] 「Export Graph as SVG」で表示中のグラフがSVG保存される
- [ ] 「Export Graph as PNG」でPNG保存される（SVG経由のラスタライズ）
- [ ] 「Copy Analysis for Coding Agent」で解析サマリとAI引継ぎプロンプトがコピーされる
- [ ] 出力ファイル名にソリューション名と粒度が入る

## エラー経路

- [ ] `.NET` が見つからない環境で、インストール案内が出て拡張が落ちない
- [ ] アナライザーが異常終了したとき、エラーメッセージと「Show Output」が表示される
- [ ] 通知のキャンセルでアナライザー子プロセスが終了する
