## 実装内容

1. **純粋関数のテスト**：reducer/query/projection/exportは既存のスイートで固定済み（SD-016/18/20/21/22）。
   本タスクでは不足していた層を埋めた。
2. **往復契約**：C#出力→TS validatorは`semanticV2.test.ts`（runtime validator + JSON Schema）で検証済み。
   逆方向の`validateHostMessage`に`reveal`（SD-019）と`viewState`（SD-021）のルールが**無い**ことが
   テストで判明したため追加した（未知typeとして拒否されていた）。
3. **ライフサイクル**：偽workerを注入し、①新しい要求が古い応答を捨てる（世代逆転）、②cancelで保留が
   拒否されworkerが終了・再生成される、③disposeで保留拒否・worker終了、④workerエラーで保留が拒否され
   終了する、⑤射影のノード寸法がワーカーへ渡る、を検証した。
4. **バグ修正**：並行して`layout()`を2回呼ぶと`ensureWorker`が**workerを2つ生成**していた（1つは
   リークし、witnessの応答が別workerから来ない）。生成中のPromiseを共有するように修正した。
5. **boundary**：同名/Unicode/長大クエリ/空集合/ページ末尾は、security（悪意ある名前）、
   protocol（クエリ上限・ID）、store（空の投影・ページ末尾）、serializer（幅クランプ）で既に固定済み。
