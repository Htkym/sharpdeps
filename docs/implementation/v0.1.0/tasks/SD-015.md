## 実装内容

1. **状態を正本にした**：`ViewState`（対象、モード、粒度、Graph/Table、スコープ、検索、
   フィルター、選択、解析状態、進捗、射影、詳細、根拠、制約、エラー、ペイン幅、履歴）と
   純粋な `viewReducer`。DOMから状態を逆算しない。描画は `app.ts` が状態から行い、
   操作はactionをdispatchするだけにした。
2. **状態の明示**：`noTarget` / `ready` / `analyzing` / `complete` / `partial` / `failed` /
   `cancelled` / `stale` を別状態として実装し、それぞれ異なる文言を出す。
   フィルターで0件のときは「該当なし＋解除ボタン」を出し、「依存なし」とは表示しない。
3. **上部バー**：対象名と相対パス、Quick/Semantic、Analyze/Stop、出力メニュー（Mermaid/SVG/
   PNG/JSON）、AIコピー、パンくず、状態文言。解析中はStopのみ有効。
4. **三領域**：左は構造/循環/解析のタブ、中央は粒度・Graph/Table・検索とデータ領域、
   右はInspector（開閉可、ドラッグとキーボードで幅変更）。splitterには `role="separator"`
   とラベルを付け、Arrowキーでリサイズできる。
5. **レスポンシブ**：1440px超は3カラム、1199px以下は左ペインを上部へ・Inspectorを
   ドロワー化、899px以下はツールバーを折り返して検索を全幅に。
6. **復元の安全化**：保存状態の復元では不正な粒度・幅・履歴を既定値へ戻し、
   `analyzing` は `ready` に落とす（無断で解析中に見せない）。

## 実装中に直した不具合

- エラーバーを `hidden` にするとグリッドの行テンプレートが繰り上がり、フッターが
  画面外へ押し出された（400px超の空行ができる）。固定行数のグリッドをやめ、
  flex column に変更した（テストは実測の高さで確認）。
- 既定の `body` marginでフッターが16px切れていたため、`html/body` のリセットを追加した。

## 判断・補足

- 既存 `media/viewer.ts`（v1・Mermaidベース）はそのまま残し、パネルの切り替えはSD-017で行う。
  移行期間のロールバック経路を確保するため。

- splitterの幅は状態（`paneWidths`）に保存し、CSS変数へ反映する。DOMの実測値を状態として
  読み戻さない。
