## 実装内容

1. **粒度集計**：解析結果は型粒度の関係のみを保持し、名前空間・プロジェクト粒度は
   両端の親をたどって集計する。同じ親に収まる関係はその粒度の辺にしない（自己辺を作らない）。
   同じ親子への複数関係は1本の辺にまとめ、**箇所数（evidenceCount）は合算**する。
2. **根拠への到達**：集計辺は `underlyingRelationIds` を持つ。UIは各関係の根拠を
   既存のページングAPIで取得できる（集計辺のidを根拠ストアへ渡す必要がない）。
3. **スコープ**：`root`（全体）、`project`/`namespace`/`type`（起点の近傍）、
   `dependencies`/`dependents`（方向と深さ1〜3）、`cycle`（循環グループのメンバー）に対応。
4. **循環フラグ**：同じ循環グループに属する両端を持つ辺を `inCycle` とする
   （ノード側は cycleGroups のメンバーシップで判定）。
5. **表示予算**：次数の降順で選択し、総数・省略数・`truncated` を返す。予算は解析結果に影響しない。
