## 実装内容

1. HEAD・基準コミット・未コミット変更を記録した。差分は `.gitignore` の1行のみで、
   利用者の未コミット変更は無かった。
2. 現行の `compile / lint / format:check / test / build:analyzer / build / package` を実行し、
   環境と結果を `baseline.md` に保存した。基準時点の失敗は無い。
3. `npx vsce ls` でVSIX同梱物を確認した。`.local/**`（内部計画書・作業ログ）が
   混入していたため `.vscodeignore` を修正し、54→41ファイルにした。
4. 実機チェックリスト `existing-features.md` を作成した（実施はSD-027）。
5. 正解付きfixture `tests/fixtures/quick-baseline/` を作成し、現行アナライザーで
   スナップショットを生成した。プロジェクト循環、条件付き参照、名前空間循環、
   未使用`using`による推定のみの辺、エイリアス`using`、global using、multi-TFM、
   非C#プロジェクトを含む。
6. スナップショット比較を `npm test` に統合した。アナライザーDLLが無い環境では
   理由付きでskipする（成功扱いにしない）。
