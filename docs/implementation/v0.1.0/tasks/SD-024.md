## 実装内容

1. **キーボード導線**：`/`で検索へフォーカス、`g`/`t`でグラフ/テーブル、`Esc`でInspectorを閉じる
   （未開なら選択解除）、グラフにフォーカスがあるとき`+`/`-`/`0`でズーム/フィット。Ctrl/Cmd/Alt併用は
   ホスト（VS Code）に譲る。入力中は文字キーとEscを奪わない。
2. **根拠→コード移動**：根拠一覧の各項目に「エディターで開く」を追加し、`openEvidence`（SD-019）を送る。
3. **focus復帰**：Inspectorを開いた時点のフォーカス要素を記憶し、閉じたときに戻す。
4. **テーマ・狭幅・モーション**：`forced-colors: active`で境界と選択状態をCanvasText/Highlightで描き、
   色だけで状態を区別しない。`prefers-reduced-motion`で遷移を停止。≤480pxでツールバーを折り返し、
   Inspectorはオーバーレイのまま92vwに抑える。
5. **選択状態の一元化（Escape修正）**：グラフ内のEscape処理を削除した。グラフが状態を介さず選択を
   消すと、アプリの同期（`setSelection`）が「新たなユーザー選択」として`relationSelected`を再発行し、
   閉じたばかりのInspectorが開き直っていた。Escapeはアプリだけが扱う。

## 判断・補足

- Escapeの所有権をアプリに一本化したのは、選択の状態（ViewState）とグラフの内部選択が二重管理に
  なっていたため。ユーザー操作は`onSelect`で状態へ、状態からグラフへは`setSelection`で戻す一方向にした。
- キー割当を純粋関数に分離し、入力中・グラフ内といった文脈依存の判定をテストで固定した。
