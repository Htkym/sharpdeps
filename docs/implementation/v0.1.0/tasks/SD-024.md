## 実装内容

1. **キーボード導線**：`/`で検索へフォーカス、`g`/`t`でグラフ/テーブル、`Esc`でInspectorを閉じる
   （未開なら選択解除）、グラフにフォーカスがあるとき`+`/`-`/`0`でズーム/フィット。Ctrl/Cmd/Alt併用は
   ホスト（VS Code）に譲る。入力中は文字キーとEscを奪わない。
2. **根拠→コード移動**：根拠一覧の各項目に「エディターで開く」を追加し、
   `openEvidence`（SD-019のホスト実装）を送る。マウスなしで 検索→型→辺→根拠→コード に到達できる。
3. **focus復帰**：Inspectorを開いた時点のフォーカス要素を記憶し、閉じたときにそこへ戻す。
4. **テーマ**：`forced-colors: active`で境界線と選択状態をCanvasText/Highlightで描き、色だけで
   状態を区別しない。`prefers-reduced-motion`で遷移とアニメーションを止める。狭幅（≤480px）で
   topbar/toolbarを折り返し、Inspectorはオーバーレイのまま幅を92vwに抑える。
5. **色以外の区別**：推定/生成/循環はバッジとARIA説明（既存）で示し、辺は種類をaria-labelに含む。

## 未検証事項

- **高コントラスト/200%表示**：CSSは追加したが、実際のテーマ（Light/Dark/HC）と200%ズームでの
  ブラウザのエミュレーションでは確認済み（境界線とtransition）。実テーマの実機確認はSD-027。
- **focus復帰の実キー確認**：Escapeで閉じることは確認できたが、Playwrightの実キー送出での
  検証スクリプトでは`inspectorOpen`が真のままで、実キー経路のfocus復帰は再確認が必要
  （合成イベント経路では閉じることを確認済み）。原因調査中：おそらくfixtureのキャッシュ。
- **scriptから表への到達**：テーブル行のEnterで詳細は開くが、行から根拠一覧へ直接移動する導線は
  未実装（辺の選択が必要）。SD-025以降の課題。
- **長い日本語の折返し**：ノードラベルはSD-004の計測に依存。狭幅での見え方はスクリーンショットで
  確認していない。

## 判断・補足

- キー割当を純粋関数に分離したのは、入力中/グラフ内といった文脈依存の判定をテストで固定するため。
- Escの解釈は「Inspectorが開いていれば閉じる、そうでなければ選択解除」。閉じたときにフォーカスを
  戻すため、記憶は再描画の外（クロージャ）で持つ。
