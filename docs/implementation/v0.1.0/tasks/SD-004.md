## 実装内容

1. 解析モデルとは独立した投影（`GraphProjection`）を定義し、ノード/辺IDは解析IDをそのまま使う。
2. ELK layeredをWorkerで実行する経路を作った。WebviewはリソースURIをfetchし、
   Blob URLからWorkerを起動する（CSPは `worker-src blob:` のみ許可）。
3. レイアウト要求にrequestIdを付け、古い応答を破棄する。キャンセルはWorkerを終了して
   pendingをrejectする（Promiseを放置しない）。
4. SVGをkeyed更新で描画する。辺には14px幅の透明hit-areaを重ね、矢印は多角形で描く。
   双方向の辺はオフセットして分離する。
5. カメラは `viewBox` とSVG要素サイズの比でズームする方式にした。
   実装中にtransform併用の二重スケールを実測で見つけて修正した（ADRに記録）。
6. 選択はノード/辺のクリックとキーボード（Tab/Enter/Escape）で行い、
   選択で再レイアウト・再Fitしない。
7. SVG/PNG出力を実装した。テーマ値をインライン化し、script・イベント属性・外部リンクを含めない。
8. 検証用の静的サーバーとCSP付きfixtureページを追加し、Playwrightで実際に動作を確認した。

## 判断・補足

- ELKは `workerFactory` で同期実行のfake workerを使う。ネストWorkerはCSPと単一バンドル方針に
  反するため採用しない。`elk-worker.min.js` に前置する1行の理由はADRとesbuild.jsに記載した。
- 検証用サーバーの `--evidence` は既定OFF。SD-027のE2E基盤として再利用する。
- 試作コードはSD-017で本番UIへ接続する前提でモジュール分割してあり、捨てる前提ではない。
