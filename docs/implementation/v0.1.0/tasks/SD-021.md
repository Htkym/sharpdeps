## 実装内容

1. **Staleの検知**：解析対象に含まれるファイルの**未保存編集**（`onDidChangeTextDocument`で
   `isDirty`）、**保存**（`onDidSaveTextDocument`）、**構成変更**（`sharpdeps`設定）で
   `stale`メッセージをパネルへ送る。対象判定はmanifestの相対パスで行い、無関係なファイルでは
   発火しない。自動更新は実装していない（既定OFFの要件を満たす）。
2. **状態の保存**：`getState/setState`（Webview）と`workspaceState`（ホスト）へ、対象名・選択・
   filter・スコープ・粒度・表示種別・検索語・ペイン幅・テーブル頁・カメラのみを保存する。
   保存は300msのdebounceで状態変化時にまとめて行う。
3. **復元**：起動時に`getState`→`stateRestored`、`ready`後にホストの`viewState`→`stateRestored`。
   **解析状態は保存しない**ため、復元で解析は起動しない（`stateRestored`は`status==='analyzing'`を
   `ready`に落とす）。版が一致しないstateは推測せず捨てる。
4. **クラッシュ耐性**：ペイン幅は140〜480/200〜720へクランプ、ズームは0.2〜6へクランプ。
   不正なスコープ（idなしの局所スコープ）はrootへ、不正なfilter・表頁は捨てる。
5. **カメラ**：射影適用時に復元カメラがあれば内容サイズを設定したうえでfitせずに適用し、
   pan/zoom後は状態へ反映して保存する。

|---|---|

## 判断・補足

- 保存対象から解析結果そのものは除外した。復元でSemanticを自動起動しない要件を、保存データの
  形で保証するため（状態にanalysisIdを持たせない）。
- 一度タイムアウトした原因は、修正前のビルドで`persistTimer`のTDZ例外によりWebviewが起動直後に
  失敗していたこと。宣言順を直し、fixtureを段階的に確認して特定した。
- カメラはズームとスクロールを復元する。fit時のviewBoxは復元しない（内容サイズは再計算する）。
