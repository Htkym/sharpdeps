## 実装内容

1. **Mermaid**：解析射影（同じ選択範囲）から `flowchart LR` を生成し、推定basisは破線
   （`-.->`）にする。既存の`sharpdeps.copyMermaid`コマンドは現行IDのまま、選択範囲のMermaidを
   クリップボードへコピーする実装に戻した。
2. **SVG/PNG**：Webviewが同じ選択範囲を描画した結果（独立表示可能なSVG、外部script・参照なし）
   を`export`メッセージの`data`として受け取り、保存ダイアログで書き出す。PNGはdata URLを復号する。
3. **JSON**：`schemaVersion: 1`と種別（`sharpdeps.selection`）、解析条件（configuration/platform）、
   completeness、limitations、選択範囲（ノード・辺・閉路）、根拠を含める。
4. **AI引継ぎ（コピー）**：対象・モード（Quickは「事実ではない」と明記）・解析条件・
   completeness・スコープと件数（表示上限の有無）・ノード一覧・関係（推定/循環の印）・根拠
   （相対パス:行:桁、生成/推定の印）・閉路（実在経路と「相互到達のみ」の区別）・limitations・
   **Do not assert**（推測を事実としない、未解析範囲を断定しない、再解析の必要性）を含む。
5. **境界**：相対パスのみ、ソース全文は含めない、snippetは明示指定時のみ。送信は一切行わず
   クリップボードへ入れて件数を通知する（利用者がコピー内容を確認できる）。

## 判断・補足

- 画像はWebviewの描画結果を`data`で受け取る方式にした。SVG/PNGはレイアウト結果（camera・配置）に
  依存し、ホスト側で同じ絵を作るにはレンダラを再実装することになるため。テキスト系（Mermaid/JSON/
  コンテキスト）はホストが解析結果から生成し、同じ選択範囲を表すことをテストで固定した。
- コンテキストの「Do not assert」節を必須にした。Quickの推定を事実として扱わないことを、
  コピー内容そのものに明記するため。
