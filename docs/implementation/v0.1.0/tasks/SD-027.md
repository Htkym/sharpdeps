## 実装内容

1. **ハーネス**：`scripts/e2e.js`は`SHARPDEPTS_VSCODE`または既知のパスのVS Codeを探し、
   無ければ`@vscode/test-electron`を使う。どちらも無い場合は**終了コード2と理由**を出す
   （無言の成功にしない）。レポートは`docs/implementation/v0.1.0/evidence/sd-027-e2e.json`へ書き出す。
2. **E2E本体**（`tests/extension/suite.js`）：拡張をactivateし、
   - 7つのコマンドIDが登録されていること、
   - ワークスペースが信頼されていること、
   - `sharpdeps.showDependencyMap`をQuick解析で実行し、**結果がストアへ登録されること**
     （`extensionTestApi.getAnalysisIds`）、
   - Problemsコレクションが取得できること、
   を検証し、JSONへ記録する。失敗は終了コードで返す。
3. **テスト用API**：`activate`の戻り値に読み取り専用の3関数（解析ID一覧・現在の解析ID・
   永続view state）を追加した。挙動は変えず、自動実行がUIと同じ状態を確認できるようにするため。

### 失敗していた原因と修正

1つ目は**検証のタイミング**で、コマンドが戻った直後にassertしていたため、コントローラが結果を
登録する前に判定していた（解析完了後に落ち着いてから確認するよう修正）。
2つ目は診断を足す過程で入り込んだ**自己原因**で、`vscode.OutputChannel.appendLine`に代入する
パッチが読み取り専用プロパティへの代入で例外になり、**拡張がactivateしていなかった**。
出力の末尾は薄いラッパーオブジェクトで捕捉するようにして解消した。
